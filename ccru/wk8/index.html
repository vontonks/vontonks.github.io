WHAT IT IS

Alphanumeric Qabbala (AQ) is a base-36 numerological scheme associated with the Cybernetic Culture Research Unit. Digits 0–9 carry their numeric values; letters a–z carry the values 10–35. The value of any word is the sum of its characters. ccru is c(12) + c(12) + r(27) + u(30) = 81.

HOW IT WORKS

Type a number between 0 and 999. The trace returns a word or phrase whose AQ value equals your input, drawn from the corpus below.

  • 0–35 returns the canonical character mapped to that value (e.g. 17 → h; 35 → z).
  • 36–200 returns a single word from the corpus whose AQ value equals your input. Inputs 36–111 draw from the full dictionary, including short fragments, abbreviations, and decades like 80s. Inputs 112–200 draw only from a stricter subset: alphabetic words, three letters or longer.
  • 201–999 partitions the input into smaller sums, each between 36 and 200, and looks up a word for each. The resulting word values sum to your input.
